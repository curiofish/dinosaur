중생대 시대 개요
**중생대(약 2억 5100만 년 전 - 6600만 년 전)**는 공룡이 지구를 지배했던 시대로, 세 개의 주요 시기로 나뉩니다:

트라이아스기 (2억 5100만 년 전 - 2억 100만 년 전)
트라이아스기는 '판게아'라는 하나의 거대한 초대륙이 존재하던 시기입니다. 이 시기에 최초의 공룡들이 등장했으며, 기후는 대체로 덥고 건조했습니다. 식물로는 고사리류, 소철류, 은행나무 조상들이 번성했습니다. 바다에서는 어룡과 같은 해양 파충류가 지배했습니다.

쥐라기 (2억 100만 년 전 - 1억 4500만 년 전)
쥐라기에 판게아 대륙은 분리되기 시작했고, 해수면이 상승하여 넓은 지역이 얕은 바다로 덮였습니다. 기후는 따뜻하고 습했으며, 거대 초식 공룡인 사우로포드(목 긴 공룡)가 번성했습니다. 이 시기에 최초의 새인 아르케옵테릭스가 나타났습니다. 쥐라기 공원 영화의 배경이 된 시대이기도 합니다.

백악기 (1억 4500만 년 전 - 6600만 년 전)
백악기는 공룡의 다양성이 최고조에 달했던 시기입니다. 대륙들이 현재와 비슷한 위치로 이동했고, 최초의 꽃피는 식물(현화식물)이 등장했습니다. 티라노사우루스 렉스, 트리케라톱스와 같은 가장 유명한 공룡들이 이 시기 후반에 살았습니다. 약 6600만 년 전, 소행성 충돌로 인한 대멸종으로 비조류 공룡들이 모두 멸종했습니다.

트라이아스기 공룡들
코엘로피시스 (Coelophysis)
작고 빠른 초기 육식 공룡으로, 길이 약 3미터, 무게는 고작 15-20kg에 불과했습니다. 길고 유연한 몸체와 가벼운 뼈를 가져 빠르게 달릴 수 있었습니다. 뉴멕시코에서 수백 마리의 화석이 한꺼번에 발견되어 무리지어 살았을 가능성이 높습니다. 작은 도마뱀이나 초기 포유류 조상들을 사냥했을 것입니다.

프라테오사우루스 (Plateosaurus)
유럽에서 발견된 초기 거대 초식 공룡으로, 길이 6-9미터, 무게 600-4,000kg에 달했습니다. 거대 사우로포드(목 긴 공룡)의 초기 조상입니다. 주로 두 다리로 서서 걸었고, 긴 목을 이용해 높은 곳의 식물도 먹을 수 있었습니다. 앞발의 엄지손가락에 큰 발톱이 있어 식물을 잡아당기는 데 사용했습니다.

에오랍토르 (Eoraptor)
'새벽의 약탈자'라는 뜻을 가진 이 공룡은 가장 초기 공룡 중 하나로, 약 2억 3,100만 년 전 남아메리카에 살았습니다. 길이 약 1미터, 무게는 겨우 10kg 정도였습니다. 특이하게도 앞니는 육식동물의 특징을, 뒷니는 초식동물의 특징을 가져 잡식성이었을 것으로 추정됩니다. 공룡 진화의 초기 단계를 보여주는 중요한 화석입니다.

헤레라사우루스 (Herrerasaurus)
초기 육식 공룡으로, 길이 3-6미터, 무게 210-350kg에 달했습니다. 날카로운 이빨과 강력한 발톱을 가졌으며, 약 2억 3,100만 년 전 아르헨티나에 살았습니다. 완전한 공룡의 특징을 아직 갖추지 않은 과도기적 형태를 보여 공룡 진화 연구에 중요한 위치를 차지합니다.

쥐라기 공룡들
디플로도쿠스 (Diplodocus)
가장 긴 공룡 중 하나로, 길이가 24-27미터에 달했지만 무게는 10-16톤으로 다른 대형 공룡에 비해 가벼운 편이었습니다. 매우 긴 목과 꼬리가 특징이며, 꼬리 끝은 채찍처럼 사용했을 가능성이 있습니다. 연필 같은 이빨로 부드러운 식물을 뜯어 먹었습니다. 머리 크기가 작고 뇌 용량도 작아 지능이 높지 않았을 것으로 추정됩니다.

브라키오사우루스 (Brachiosaurus)
'팔 도마뱀'이라는 뜻의 이 공룡은 앞다리가 뒷다리보다 길어서 기린처럼 몸이 앞으로 기울어진 모습이었습니다. 높이가 13미터에 달해 4층 건물만큼 높았으며, 무게는 35-58톤이었습니다. 이 특별한 체형 덕분에 높은 나무의 잎을 먹을 수 있었습니다. 심장은 엄청난 압력으로 피를 머리까지 펌프질해야 했기 때문에 매우 강력했을 것입니다.

스테고사우루스 (Stegosaurus)
등에 2열로 배열된 17개의 큰 뼈 판과 꼬리 끝의 4개의 가시가 특징인 공룡입니다. 길이 약 9미터, 무게 5-7톤이었습니다. 뼈 판은 체온 조절과 과시용으로 사용되었을 것으로 추정됩니다. 뇌가 호두 크기로 매우 작아 "두 번째 뇌"가 있었다는 오해를 받기도 했지만, 실제로는 엉덩이 부분의 신경 덩어리일 뿐이었습니다.

알로사우루스 (Allosaurus)
쥐라기 후기의 최상위 포식자로, 길이 8-12미터, 무게 1.5-2.5톤이었습니다. 눈 위의 뿔 같은 돌기가 특징이며, 강력한 턱과 날카로운 이빨을 가졌습니다. 발견된 많은 화석은 이 공룡이 위험한 생활을 했음을 보여주는 상처와 골절 흔적이 있습니다. 싸우는 동안 머리를 도끼처럼 사용했을 가능성이 있으며, 무리를 지어 큰 사우로포드도 사냥했을 것으로 추정됩니다.

아르케옵테릭스 (Archaeopteryx)
'고대의 날개'라는 뜻을 가진 이 생물은 공룡과 새의 특징을 모두 가진 중간 형태였습니다. 까마귀 크기로, 깃털과 날개가 있었지만 공룡의 특징인 이빨, 긴 꼬리, 발톱 달린 손가락도 가졌습니다. 완벽하게 날 수 있었는지는 확실하지 않지만, 짧은 거리는 날 수 있었을 것으로 추정됩니다. 공룡과 조류의 진화적 연결고리를 보여주는 중요한 화석입니다.

백악기 공룡들
티라노사우루스 렉스 (Tyrannosaurus rex)
'폭군 도마뱀 왕'이라는 뜻의 이 공룡은 역사상 가장 유명한 육식 공룡입니다. 길이 12-14미터, 무게 8-14톤으로, 육상 육식동물 중 가장 큰 동물 중 하나였습니다. 30cm 길이의 이빨과 6,000kg의 물림 힘으로 뼈를 부술 수 있었습니다. 앞다리는 매우 작았지만 두 다리로 시속 30km까지 달릴 수 있었다고 추정됩니다. 최근 연구에 따르면 일부 깃털이 있었을 가능성도 제기되고 있습니다.

트리케라톱스 (Triceratops)
'세 개의 뿔 얼굴'이라는 뜻을 가진 이 공룡은 이마에 두 개의 긴 뿔과 코 위에 짧은 뿔, 그리고 뒤통수를 덮는 커다란 프릴이 특징입니다. 길이 약 8-9미터, 무게 6-12톤이었습니다. 프릴과 뿔은 티라노사우루스 같은 포식자로부터 방어하거나 같은 종끼리의 경쟁에 사용되었을 것입니다. 단단한 부리로 딱딱한 식물도 먹을 수 있었습니다.

벨로시랍토르 (Velociraptor)
영화 '쥐라기 공원'으로 유명해진 이 공룡은 실제로는 크기가 훨씬 작았습니다. 키 0.5미터, 길이 2미터, 무게 15kg 정도로, 칠면조 크기에 불과했습니다. 몸 전체가 깃털로 덮여 있었고, 발의 두 번째 발가락에 큰 발톱이 있어 사냥감을 공격하는 데 사용했습니다. 매우 지능적이었으며, 한 화석에서는 프로토케라톱스와 싸우다 죽은 모습이 발견되기도 했습니다.

파라사우롤로푸스 (Parasaurolophus)
'옆의 볏 있는 도마뱀'이라는 뜻의 이 공룡은 머리 뒤로 1.8미터 길이의 중공 관이 특징입니다. 길이 약 10미터, 무게 2.5톤이었습니다. 이 관은 다양한 소리를 내어 무리 내 의사소통을 하는 데 사용되었을 것으로 추정됩니다. 과학자들이 이 관의 모형을 만들어 소리를 재현해 본 결과, 트럼본과 비슷한 낮은 음색의 소리를 냈을 것으로 생각됩니다.

안킬로사우루스 (Ankylosaurus)
'굽은 도마뱀'이라는 뜻의 이 공룡은 등과 옆구리가 골질 판과 가시로 덮여 있고, 꼬리 끝에는 골질 곤봉이 있었습니다. 길이 약 8-9미터, 무게 6톤이었습니다. 이런 갑옷은 티라노사우루스와 같은 포식자로부터 보호해 주었을 것입니다. 꼬리 곤봉은 무게가 약 50kg이었으며, 이를 휘둘러 포식자의 다리를 부러뜨릴 수 있었을 것입니다.

생각 과정
초등학생을 위한 공룡 분류 방식에 대한 의견
네, 전적으로 동의합니다! 서식 환경과 식성에 따른 분류는 초등학생들에게 여러 면에서 더 흥미롭고 효과적일 것입니다.

서식 환경/식성 분류가 더 적합한 이유:
직관적 이해가 쉽습니다 초등학생들은 "누가 누구를 잡아먹었는지", "어디서 살았는지"와 같은 구체적인 생활 방식이 더 이해하기 쉽고 흥미롭습니다. 시대 구분(2억년 전, 1억년 전)은 너무 추상적이고 와닿지 않을 수 있습니다.

상상력을 자극합니다 "거대한 초식공룡이 높은 나무 잎을 먹는 모습" 또는 "날카로운 이빨을 가진 육식공룡이 사냥하는 모습"은 아이들의 상상력을 자극하고 흥미를 유발합니다.

생생한 스토리텔링이 가능합니다 "하늘의 지배자들", "바다의 거인들", "육지의 포식자들"처럼 드라마틱한 주제로 구성할 수 있어 아이들이 더 몰입할 수 있습니다.

교육적 연결성이 좋습니다 생태계, 먹이사슬, 적응과 진화의 개념을 자연스럽게 이해할 수 있게 합니다. "왜 스피노사우루스는 악어 같은 주둥이를 가졌을까?" 같은 질문으로 이어질 수 있습니다.

놀이와 활동으로 연결하기 쉽습니다 "육식공룡 vs 초식공룡 게임", "공중 공룡 날리기", "해양 공룡 수영하기" 같은 활동으로 자연스럽게 이어질 수 있습니다.

효과적인 백과사전 구성 제안:
주요 분류는 서식 환경과 식성으로 합니다

육지의 거인들(초식공룡)
무시무시한 사냥꾼들(육식공룡)
하늘의 지배자들(날아다니는 파충류)
바다의 거대 괴물들(수생 파충류)
각 소개에 시대 정보를 부가적으로 포함합니다

예: "트리케라톱스는 백악기 말기에 살았던 뿔 달린 초식공룡으로..."
시대별 개요는 별도 섹션으로 간략히 다룹니다 백과사전 도입부나 부록에 시간선(타임라인)과 함께 각 시대의 특징을 간략히 소개하는 방식이 좋겠습니다.

시각적 요소를 강화합니다 각 카테고리별로 색상 코드를 사용하고(예: 육식공룡은 빨강, 초식공룡은 초록), 해당 공룡의 크기 비교, 특징적인 부위 확대도, 생활 모습 일러스트 등을 포함하면 더욱 효과적일 것입니다.

초등학생들은 이런 실용적이고 직관적인 분류 방식을 통해 공룡에 더 쉽게 접근하고, 더 오래 기억에 남는 학습 경험을 할 수 있을 것입니다. 시대별 분류는 보조 정보로 활용하되, 주요 구성은 생태와 식성 중심으로 하는 것이 최적의 접근법이라고 생각합니다.

function initHeroSlider() {
    // 슬라이더 이미지 배열
    const sliderImages = [
        'images/hero-bg.jpg',
        'images/hero-bg2.jpg',
        'images/hero-bg3.jpg'
    ];
    
    let currentSlide = 0;
    
    // 배경 이미지 변경 함수
    function changeBackground() {
        document.getElementById('hero').style.backgroundImage = `linear-gradient(rgba(0, 0, 0, 0.5), rgba(0, 0, 0, 0.5)), url('${sliderImages[currentSlide]}')`;
        currentSlide = (currentSlide + 1) % sliderImages.length;
    }
    
    // 초기 배경 설정
    changeBackground();
    
    // 7초마다 배경 변경
    setInterval(changeBackground, 7000);
}

// 타임라인 슬라이더 초기화
function initTimelineSlider() {
    let isDragging = false;
    const slider = document.querySelector('.timeline-slider');
    const sliderRect = slider.getBoundingClientRect();
    const sliderWidth = sliderRect.width;
    
    // 타임라인 위치에 따라 시대 정보 표시
    function updateEraInfo(position) {
        const percentage = position / sliderWidth * 100;
        
        // 모든 카드 숨기기
        eraCards.forEach(card => card.classList.remove('active'));
        
        // 위치에 따라 적절한 시대 카드 표시
        if (percentage < 30) {
            document.getElementById('triassic').classList.add('active');
        } else if (percentage < 65) {
            document.getElementById('jurassic').classList.add('active');
        } else {
            document.getElementById('cretaceous').classList.add('active');
        }
    }
    
    // 핸들 이동 함수
    function moveHandle(e) {
        if (!isDragging) return;
        
        let clientX;
        if (e.type === 'touchmove') {
            clientX = e.touches[0].clientX;
        } else {
            clientX = e.clientX;
        }
        
        const sliderRect = slider.getBoundingClientRect();
        let position = clientX - sliderRect.left;
        
        // 슬라이더 범위 내로 제한
        position = Math.max(0, Math.min(position, sliderRect.width));
        
        // 핸들 위치 업데이트
        const leftPercentage = (position / sliderRect.width) * 100;
        timelineHandle.style.left = `${leftPercentage}%`;
        
        // 시대 정보 업데이트
        updateEraInfo(position);
    }
    
    // 마우스/터치 이벤트 리스너
    timelineHandle.addEventListener('mousedown', () => {
        isDragging = true;
    });
    
    timelineHandle.addEventListener('touchstart', () => {
        isDragging = true;
    });
    
    document.addEventListener('mousemove', moveHandle);
    document.addEventListener('touchmove', moveHandle);
    
    document.addEventListener('mouseup', () => {
        isDragging = false;
    });
    
    document.addEventListener('touchend', () => {
        isDragging = false;
    });
    
    // 시대 마커 클릭 이벤트
    const eraMarkers = document.querySelectorAll('.era-mark');
    eraMarkers.forEach(marker => {
        marker.addEventListener('click', function() {
            const leftPercentage = parseFloat(this.style.left);
            timelineHandle.style.left = `${leftPercentage}%`;
            
            // 시대 정보 업데이트
            updateEraInfo((leftPercentage / 100) * sliderWidth);
        });
    });
    
    // 초기 시대 정보 표시
    updateEraInfo(0.1 * sliderWidth);
}

육지의 거인들 (초식공룡)
거대 사우로포드 (목 긴 공룡)

브라키오사우루스 (Brachiosaurus) '팔 도마뱀'이라는 뜻의 브라키오사우루스는 쥐라기 후기(1억 5,400만 년 전)에 살았던 초대형 공룡입니다. 앞다리가 뒷다리보다 길어 몸이 기린처럼 기울어진 독특한 체형을 가졌습니다. 키가 13미터(4층 건물 높이)에 달했고, 무게는 35-58톤이었습니다.

브라키오사우루스의 콧구멍은 머리 위쪽에 있어, 과거에는 물속 생활에 적응한 것으로 오해받았습니다. 그러나 현재는 코를 통해 고효율로 열을 배출했을 것으로 추측합니다. 이 공룡의 심장은 머리까지 피를 펌프질하기 위해 매우 강력했을 것이며, 머리를 들어올릴 때마다 크게 변화하는 혈압을 조절할 수 있는 특별한 시스템이 있었을 것입니다.

디플로도쿠스 (Diplodocus) 가장 긴 공룡 중 하나로, 길이가 무려 24-27미터에 달했지만 무게는 10-16톤으로 다른 대형 공룡에 비해 가벼운 편이었습니다. 쥐라기 후기 북아메리카에 살았으며, 극도로 긴 목과 꼬리가 특징입니다. 꼬리 끝부분은 채찍처럼 소리를 낼 수 있었고, 포식자로부터 자신을 방어하는 무기로 사용했을 것입니다.

디플로도쿠스의 이빨은 연필처럼 가늘었고 앞쪽에만 있었는데, 이는 나뭇잎을 훑어 뜯어먹는 데 특화된 형태입니다. 이들은 머리를 흔들어 나뭇잎을 훑어내는 방식으로 채식했을 것으로 추정됩니다. 또한 소화를 돕기 위해 위 속에 작은 돌(위석)을 삼켰을 가능성이 높습니다.

아르겐티노사우루스 (Argentinorsaurus) 현재까지 발견된 가장 큰 육상 동물 중 하나로 추정되는 이 거대 공룡은 백악기 초기(약 9,400만 년 전) 아르헨티나에 살았습니다. 길이 약 30-40미터, 무게 60-100톤으로 추정되며, 척추뼈 하나의 높이만 1.5미터에 달했습니다.

이 거대한 체구로 인해 아르겐티노사우루스는 천천히 움직였을 것으로 추정되며, 심장에서 머리까지 혈액을 펌프질하는 데 필요한 압력은 엄청났을 것입니다. 일부 연구자들은 이들에게 여러 개의 '보조 심장'이 있었을 가능성을 제기하기도 합니다.

뿔 공룡들 (각질 공룡)

트리케라톱스 (Triceratops) '세 개의 뿔 얼굴'이라는 뜻을 가진 트리케라톱스는 백악기 최후기(약 6,800만 년 전)에 북아메리카에 살았습니다. 이마에 두 개의 긴 뿔(최대 1미터 길이)과 코 위에 짧은 뿔, 그리고 뒤통수를 덮는 커다란 프릴(목 덮개)이 특징입니다. 길이 약 8-9미터, 무게 6-12톤에 달했습니다.

트리케라톱스의 뿔과 프릴은 티라노사우루스 같은 포식자로부터 방어하거나 같은 종끼리의 경쟁에 사용되었을 것입니다. 화석에서 발견된 손상 흔적은 이들이 서로 뿔로 싸웠다는 증거입니다. 단단한 부리로 딱딱한 식물도 먹을 수 있었고, 한 번에 800개 이상의 이빨을 가졌는데, 닳으면 새 이빨이 자라나는 시스템이었습니다.

스티라코사우루스 (Styracosaurus) '가시 도마뱀'이라는 뜻의 이 공룡은 백악기 후기(약 7,500만 년 전) 북아메리카에 살았습니다. 길이 약 5.5미터, 무게 약 3톤이었으며, 화려한 프릴에서 뻗어나온 4-6개의 긴 가시와 코 위의 큰 뿔이 특징입니다.

이 화려한 장식은 포식자 방어, 체온 조절, 그리고 짝짓기 디스플레이에 사용되었을 것입니다. 스티라코사우루스는 무리를 지어 살았을 가능성이 높으며, 프릴의 패턴과 색상은 개체 식별에 도움이 되었을 것입니다.

갑옷 공룡들 (판갑 공룡)

스테고사우루스 (Stegosaurus) 쥐라기 후기(약 1억 5,000만 년 전) 북아메리카에 살았던 이 공룡은 등에 2열로 배열된 17개의 큰 뼈 판과 꼬리 끝의 4개의 가시가 특징입니다. 길이 약 9미터, 무게 5-7톤이었습니다.

뼈 판은 체온 조절(열 방출 및 흡수)과 과시용으로 사용되었을 것으로 추정됩니다. 스테고사우루스 판에는 많은 혈관이 있어 피부 색을 변화시키거나 체온 조절에 이용했을 가능성이 있습니다. 꼬리 가시('타이고스타크스'라고 불림)는 방어 무기였으며, 알로사우루스와 같은 포식자에게 치명적인 상처를 입힐 수 있었습니다.

스테고사우루스의 뇌는 호두 크기(약 80g)로 매우 작았지만, 엉덩이 부근에는 신경 덩어리(신경절)가 있어 뒷부분 움직임을 제어했습니다. 이것이 "두 번째 뇌"라는 오해를 받기도 했습니다.

안킬로사우루스 (Ankylosaurus) '굽은 도마뱀'이라는 뜻의 이 공룡은 백악기 최후기(약 6,800-6,600만 년 전) 북아메리카에 살았습니다. 등과 옆구리가 골질 판과 가시로 덮여 있고, 꼬리 끝에는 무게 약 50kg의 골질 곤봉이 있었습니다. 길이 약 8-9미터, 무게 6톤이었습니다.

안킬로사우루스의 갑옷은 수천 개의 작은 뼈 조각이 피부에 박혀 만들어졌으며, 티라노사우루스와 같은 포식자의 공격에도 상당한 보호 기능을 제공했습니다. 꼬리 곤봉은 포식자의 다리를 부러뜨릴 수 있을 정도로 강력했으며, 같은 종끼리의 경쟁에도 사용되었을 가능성이 있습니다.

오리주둥이 공룡들

파라사우롤로푸스 (Parasaurolophus) '옆의 볏 있는 도마뱀'이라는 뜻의 이 공룡은 백악기 후기(약 7,600만 년 전) 북아메리카에 살았습니다. 머리 뒤로 1.8미터 길이의 중공 관이 특징이며, 길이 약 10미터, 무게 2.5톤이었습니다.

파라사우롤로푸스의 긴 머리 관은 소리를 내는 데 사용되었는데, 과학자들이 이 관의 3D 모델을 만들어 소리를 재현해 본 결과, 트럼본과 비슷한 낮은 음색의 소리를 냈을 것으로 추정됩니다. 이 소리는 무리 내 의사소통, 포식자 경고, 짝 찾기에 사용되었을 것입니다. 또한 머리 관의 크기와 모양은 성별과 연령에 따라 달랐을 가능성이 높습니다.

코리토사우루스 (Corythosaurus) '투구 도마뱀'이라는 뜻의 이 공룡은 백악기 후기(약 7,700만 년 전) 북아메리카에 살았습니다. 머리 위에 카사왈리 새의 머리 장식과 비슷한 형태의 벼슬을 가졌습니다. 길이 약 9미터, 무게 3-5톤이었습니다.

코리토사우루스의 머리 벼슬도 파라사우롤로푸스와 마찬가지로 내부가 비어 있어 소리를 내는 데 사용되었으며, 또한 체온 조절이나 종 식별의 기능도 했을 것입니다. 이 공룡은 입안에 수백 개의 이빨을 가졌으며, 식물을 효율적으로 씹어 먹을 수 있었습니다.

마이아사우라 (Maiasaura) '좋은 어미 도마뱀'이라는 뜻의 이 공룡은 백악기 후기(약 7,600만 년 전) 북아메리카에 살았습니다. 길이 약 9미터, 무게 3-4톤이었습니다.

마이아사우라는 발견된 화석을 통해 새끼를 돌보는 육아 행동이 확인된 최초의 공룡입니다. 몬태나주에서 발견된 집단 둥지 유적에서는 성체, 새끼, 알이 함께 발견되었습니다. 새끼들의 다리 뼈 상태로 보아 부화 후 성체가 먹이를 가져다주는 방식으로 돌봄을 받았을 것으로 추정됩니다. 이는 공룡의 사회적 행동을 보여주는 중요한 증거입니다.

무시무시한 사냥꾼들 (육식공룡)
거대 포식자들

티라노사우루스 렉스 (Tyrannosaurus rex) '폭군 도마뱀 왕'이라는 뜻의 티라노사우루스 렉스는 백악기 최후기(약 6,800-6,600만 년 전) 북아메리카에 살았던 역사상 가장 유명한 육식 공룡입니다. 길이 12-14미터, 무게 8-14톤이었습니다.

티라노사우루스는 가장 강력한 물림힘을 가진 육상 포식자로, 물림힘은 약 6,000kg으로 추정되며, 최대 30cm 길이의 이빨로 트리케라톱스의 뼈도 부술 수 있었습니다. 앞다리는 매우 작았지만 두 다리로 시속 30km까지 달릴 수 있었다고 추정됩니다.

최근 연구에 따르면 티라노사우루스는 기존에 생각했던 것보다 훨씬 뛰어난 감각을 가졌습니다. 뇌 구조 분석 결과 매우 발달된 후각과 청각, 균형 감각을 가졌으며, 눈은 독수리처럼 정밀한 색채 인식이 가능했고 움직임에 매우 민감했을 것으로 추정됩니다.

흥미롭게도 티라노사우루스의 유생(새끼)과 청소년기 개체들은 성체와 상당히 달랐습니다. 어린 개체들은 가늘고 긴 다리를 가졌으며, 민첩하고 빠른 사냥꾼이었고, 깃털 덮개가 있었을 가능성이 높습니다. 성장하면서 체형이 변하고 더 강력하지만 느려지는 방향으로 진화했습니다.

스피노사우루스 (Spinosaurus) '가시 도마뱀'이라는 뜻의 스피노사우루스는 백악기 중기(약 1억 1,200-9,400만 년 전) 북아프리카에 살았습니다. 티라노사우루스보다 더 길었을 가능성이 있는(15-18미터) 이 공룡은 등에 1.5-2미터 높이의 돛 모양 가시가 특징이었습니다.

2014년 이후 연구에 따르면, 스피노사우루스는 수생 생활에 적응한 최초의 수영하는 공룡이었을 가능성이 높습니다. 짧은 후지와 밀도 높은 뼈, 악어와 유사한 코와 이빨 구조, 그리고 가능성 있는 물갈퀴 발이 이를 뒷받침합니다. 최근 발견된 꼬리 화석은 이전에 생각했던 것보다 훨씬 넓고 패들 형태여서, 수영 추진력을 제공했을 것으로 보입니다.

스피노사우루스의 식단은 주로 대형 물고기였을 것으로 추정되며, 악어처럼 물가에서 사냥했을 것입니다. 등의 돛은 체온 조절, 짝짓기 과시, 수영 중 안정화 등의 용도로 사용되었을 가능성이 있습니다.

기가노토사우루스 (Giganotosaurus) '거대한 남방 도마뱀'이라는 뜻의 기가노토사우루스는 백악기 중기(약 9,700만 년 전) 남아메리카에 살았습니다. 길이 12-13미터, 무게 8-14톤으로, 티라노사우루스와 비슷한 크기였지만 더 가볍고 빠른 체형을 가졌습니다.

기가노토사우루스는 현존하는 가장 큰 육상 동물인 코끼리보다 더 무거웠으며, 그 시대 남아메리카에 살았던 거대 초식공룡 아르겐티노사우루스를 사냥했을 가능성이 있습니다. 아마도 무리를 지어 사냥했을 것으로 추정됩니다.

이 공룡의 두개골은 약 1.8미터로 티라노사우루스보다 길었지만, 이빨은 더 작고 날카로웠으며 물림힘도 약했습니다. 이는 다른 사냥 전략을 사용했음을 시사합니다 - 강력한 턱으로 부수기보다는 날카로운 이빨로 깊은 상처를 내는 방식이었을 것입니다.

날렵한 사냥꾼들

벨로시랍토르 (Velociraptor) '빠른 약탈자'라는 뜻의 벨로시랍토르는 백악기 후기(약 7,500만 년 전) 몽골을 포함한 중앙아시아 지역에 살았습니다. 영화 '쥐라기 공원'으로 유명해졌지만, 실제로는 크기가 훨씬 작았습니다 - 키 0.5미터, 길이 2미터, 무게 15kg 정도로, 칠면조 크기에 불과했습니다.

벨로시랍토르의 몸 전체는 깃털로 덮여 있었으며, 오늘날의 새와 매우 유사했습니다. 발의 두 번째 발가락에는 7.5cm 길이의 낫 모양 발톱이 있어, 사냥감을 공격하는 데 사용했습니다.

가장 유명한 벨로시랍토르 화석은 "싸우는 공룡들"로 알려진 것으로, 프로토케라톱스와 싸우다 모래폭풍에 묻힌 모습이 그대로 보존되었습니다. 이 화석은 벨로시랍토르가 실제로 적극적인 포식자였음을 보여주는 증거입니다.

유타랍토르 (Utahraptor) '유타의 약탈자'라는 뜻의 유타랍토르는 백악기 초기(약 1억 2,600만 년 전) 북아메리카에 살았습니다. 벨로시랍토르의 친척이지만 훨씬 컸습니다 - 길이 7미터, 무게 500kg 이상으로, 랍토르 중 가장 큰 종이었습니다.

유타랍토르는 발에 23cm 길이의 거대한 발톱을 가졌으며, 이를 이용해 자신보다 훨씬 큰 사냥감도 공격할 수 있었습니다. 과학자들은 유타랍토르가 당시 북아메리카에 살았던 이구아노돈과 같은 대형 초식공룡을 무리 사냥했을 것으로 추측합니다.

최근 연구에 따르면 유타랍토르도 벨로시랍토르처럼 깃털로 덮여 있었을 가능성이 높습니다. 유타주에서 발견된 한 화석 덩어리에는 여러 개체의 유타랍토르가 함께 있었는데, 이는 무리 생활을 했음을 시사합니다.

트로오돈 (Troodon) '날카로운 이빨'이라는 뜻의 트로오돈은 백악기 후기(약 7,600만 년 전) 북아메리카에 살았습니다. 길이 2-3미터, 무게 50kg 정도였으며, 공룡 중에서 뇌 크기 대비 체중 비율이 가장 높아 가장 지능이 높았던 공룡으로 여겨집니다.

트로오돈의 눈은 매우 크고 앞쪽을 향해 있어 뛰어난 입체 시각을 가졌으며, 야간 활동에 적합했을 것으로 추정됩니다. 톱니 모양의 작은 이빨은 고기와 식물을 모두 먹는 잡식성이었음을 시사합니다.

특히 흥미로운 점은 트로오돈이 알을 품는 방식이 오늘날의 새와 매우 유사했다는 것입니다. 발견된 화석 둥지는 트로오돈이 알을 일정한 온도로 유지하기 위해 몸으로 덮고 있었음을 보여줍니다. 이는 조류의 행동과 매우 유사하며, 공룡과 조류 사이의 진화적 연결을 강화하는 증거입니다.

소형 육식공룡

컴프소그나투스 (Compsognathus) '예쁜 턱'이라는 뜻의 컴프소그나투스는 쥐라기 후기(약 1억 5,000만 년 전) 유럽에 살았습니다. 길이 약 1미터, 무게 3kg 정도로, 닭 크기에 불과했습니다.

이 작은 공룡은 빠르고 민첩했으며, 주로 도마뱀이나 작은 포유류를 사냥했습니다. 한 화석 표본에서는 소화되지 않은 도마뱀이 배 부분에서 발견되기도 했습니다. 발달된 시각을 가졌으며, 긴 꼬리는 빠르게 방향을 바꿀 때 균형 유지에 도움이 되었을 것입니다.

컴프소그나투스는 초기에 발견된 공룡 중 하나로, 과학자들이 공룡과 조류의 연관성을 이해하는 데 중요한 역할을 했습니다. 최근 연구에 따르면 몸에 깃털 같은 구조가 있었을 가능성이 높습니다.

코엘로피시스 (Coelophysis) '중공의 형태'라는 뜻의 코엘로피시스는 트라이아스기 후기(약 2억 1,500만 년 전) 북아메리카에 살았던 초기 공룡입니다. 길이 약 3미터, 무게 15-20kg로, 가볍고 민첩한 체형을 가졌습니다.

코엘로피시스는 텅 빈 뼈를 가진 가벼운 골격 구조를 가져 매우 빠르게 달릴 수 있었습니다. 긴 목과 꼬리, 그리고 유연한 몸체로 빠르게 방향을 전환할 수 있었습니다. 날카로운 이빨과 강한 턱으로 작은 동물을 사냥했으며, 기회가 되면 다른 코엘로피시스도 잡아먹는 공식(共食) 행동을 했을 가능성도 있습니다.

뉴멕시코 고스트 랜치에서는 수백 마리의 코엘로피시스 화석이 한꺼번에 발견되었는데, 이는 이들이 무리를 지어 살았거나, 홍수와 같은 자연재해로 한꺼번에 사망했을 가능성을 시사합니다.

하늘의 지배자들 (비행 파충류)
거대 익룡들

케찰코아틀루스 (Quetzalcoatlus) '깃털 달린 뱀 신'이라는 뜻의 케찰코아틀루스는 백악기 최후기(약 7,000-6,600만 년 전) 북아메리카에 살았던 역사상 가장 큰 비행 동물 중 하나입니다. 기린 높이만큼 키가 컸으며(지상에서 높이 5-6미터), 날개 폭은 10-11미터에 달했습니다.

이 거대한 익룡은 주로 육상에서 네 발로 걸어다녔으며, 현대 기린처럼 굉장히 긴 목을 가졌습니다. 비행 시에는 열기류를 이용한 글라이딩에 뛰어났으며, 에너지를 보존하기 위해 활공 비행을 주로 했을 것으로 추정됩니다.

케찰코아틀루스의 식단은 아직 논쟁 중이지만, 긴 부리로 작은 육상 동물이나 물고기를 사냥했을 가능성이 높습니다. 일부 연구자들은 이들이 현대의 황새처럼 지상에서 먹이를 찾았을 것으로 추측합니다. 그들의 부리는 날카롭고 이빨이 없었으며, 턱 근육은 강력했습니다.

프테라노돈 (Pteranodon) '이빨 없는 날개'라는 뜻의 프테라노돈은 백악기 후기(약 8,600-8,000만 년 전) 북아메리카에 살았습니다. 날개 폭이 7미터에 달했으며, 수컷의 경우 머리 뒤로 길게 뻗은 볏이 특징이었습니다.

프테라노돈은 현대 해양 조류와 유사한 생활 방식을 가졌을 것으로 추정됩니다. 대부분의 시간을 바다 위를 날면서 물고기를 사냥했으며, 이빨 대신 부리를 가졌습니다. 긴 하늘 비행에 적응되어 있어, 현대의 알바트로스처럼 장거리 비행에 특화되었을 가능성이 높습니다.

램포린쿠스 (Rhamphorhynchus) '부리 주둥이'라는 뜻의 램포린쿠스는 쥐라기 후기(약 1억 5,000만 년 전) 유럽에 살았습니다. 날개 폭 1.8미터, 다이아몬드 모양의 꼬리 끝 판이 특징이었습니다.

램포린쿠스는 물 위를 낮게 날면서 부리를 물에 담가 물고기를 잡는 방식으로 사냥했을 것으로 추정됩니다. 꼬리 끝의 판은 비행 안정성을 제공했으며, 날카로운 이빨은 미끄러운 물고기를 잡기에 적합했습니다.

특히 흥미로운 점은 일부 화석에서 날개막의 미세한 구조까지 보존되어 있다는 것입니다. 이를 통해 램포린쿠스의 날개막은 근육과 혈관이 풍부해 적극적으로 비행 중 형태를 조절할 수 있었음이 밝혀졌습니다.

조류 공룡들

아르케옵테릭스 (Archaeopteryx) '고대의 날개'라는 뜻의 아르케옵테릭스는 쥐라기 후기(약 1억 5,000만 년 전) 유럽에 살았습니다. 까마귀 크기(길이 0.5미터)로, 공룡과 새의 특징을 모두 가진 중간 형태였습니다.

아르케옵테릭스는 깃털과 날개가 있었지만 공룡의 특징인 이빨, 긴 뼈로 된 꼬리, 발톱 달린 손가락도 가졌습니다. 이 화석은 공룡과 조류의 진화적 연결을 보여주는 중요한 증거로, "잃어버린 고리"로 불리기도 합니다.

완벽하게 날 수 있었는지는 확실하지 않지만, 짧은 거리는 날 수 있었을 것으로 추정됩니다. 나무를 타고 활강하는 생활 방식을 가졌을 가능성이 높으며, 작은 도마뱀이나 곤충을 사냥했을 것입니다.

미크로랍토르 (Microraptor) '작은 약탈자'라는 뜻의 미크로랍토르는 백악기 초기(약 1억 2,000만 년 전) 중국 북동부에 살았습니다. 길이 약 77cm, 무게 1kg 정도로, 네 개의 날개를 가진 놀라운 공룡이었습니다.

미크로랍토르는 앞다리와 뒷다리 모두에 잘 발달된 깃털 날개를 가졌으며, 이는 나비와 같은 '4-날개' 비행 구성을 이루었습니다. 이러한 구조는 나무에서 나무로 활공하는 데 적합했을 것으로 추정됩니다. 또한 꼬리에도 깃털이 있어 비행 시 안정성을 제공했습니다.

특히 흥미로운 점은 미크로랍토르의 깃털이 까맣게 빛났다는 증거가 있다는 것입니다. 화석에 보존된 멜라노좀(색소 세포)을 분석한 결과, 이 공룡은 오늘날의 까마귀처럼 푸른빛을 띤 검은색이었을 것으로 추정됩니다.

이이안다 (Yi qi) '이상한 날개'라는 뜻의 이이안다는 쥐라기 중기(약 1억 6,000만 년 전) 중국에 살았습니다. 2015년 발견된 이 특이한 공룡은 공룡 세계의 '플라잉 스퀴럴'로 불립니다.

이이안다의 가장 놀라운 특징은 다른 깃털 공룡과 달리, 박쥐와 유사한 막 형태의 날개를 가졌다는 점입니다. 길게 늘어난 손가락 뼈가 피부막을 지지하는 구조였으며, 이는 공룡에서는 유일한 사례입니다. 이 발견은 공룡이 비행을 위해 다양한 진화 경로를 실험했음을 보여줍니다.

바다의 공포 (해양 파충류)
해양 괴물들

모사사우루스 (Mosasaurus) '뫼즈강 도마뱀'이라는 뜻의 모사사우루스는 백악기 후기(약 8,200-6,600만 년 전)에 전 세계 바다에 살았던 거대 해양 파충류입니다. 길이 15-18미터, 무게 15톤 이상으로, 오늘날의 대형 고래만큼 컸습니다.

모사사우루스는 공룡이 아닌, 현대 도마뱀과 뱀의 조상과 가까운 해양 파충류였습니다. 강력한 지느러미와 꼬리를 이용해 빠르게 수영했으며, 거대한 턱에는 70개 이상의 날카로운 이빨이 있었습니다. 이들은 물고기, 오징어, 암모나이트, 바다거북, 심지어 다른 모사사우루스도 사냥했습니다.

최근 연구에 따르면 모사사우루스는 상어와 같은 이중 꼬리지느러미(위쪽이 더 큰)를 가졌을 가능성이 있으며, 피부는 매끄러운 비늘로 덮여 있어 수중에서 빠르게 움직일 수 있었습니다.

플레시오사우루스 (Plesiosaurs) '가까운 도마뱀'이라는 뜻의 플레시오사우루스류는 쥐라기-백악기(약 2억-6,600만 년 전)에 전 세계 바다에 살았던 해양 파충류 그룹입니다. 독특한 체형으로, 거북이 같은 넓은 몸체, 매우 긴 목, 그리고 네 개의 강력한 지느러미를 가졌습니다.

플레시오사우루스류 중 가장 극단적인 예는 엘라스모사우루스로, 목의 길이가 7미터가 넘었고(전체 길이의 절반 이상), 최대 70개의 목뼈를 가졌습니다. 이 긴 목은 물고기 무리에 몰래 접근하여 빠르게 공격하는 데 사용되었을 것입니다.

이들은 잠재적 천적을 360도로 살피기에 적합한 눈 위치를 가졌으며, 네 개의 지느러미를 새와 같은 방식으로 움직여 '수중 비행'을 했습니다. 최근 화석 발견은 플레시오사우루스가 새끼를 낳는(난태생) 방식으로 번식했으며, 아마도 현대 돌고래처럼 새끼를 돌봤을 가능성을 시사합니다.

익티오사우루스 (Ichthyosaurs) '물고기 도마뱀'이라는 뜻의 익티오사우루스류는 트라이아스기-백악기(약 2억 5,000만-9,000만 년 전)에 전 세계 바다에 살았던 해양 파충류 그룹입니다. 이들은 독립적으로 돌고래와 매우 유사한 형태로 진화했습니다.

익티오사우루스는 유선형 몸체, 등지느러미, 반달 모양의 꼬리지느러미를 가졌으며, 일부 종은 시속 40km 이상의 속도로 수영할 수 있었습니다. 현대 돌고래나 참치와 마찬가지로 온혈성이었을 가능성이 높습니다. 매우 큰 눈을 가져 깊은 바다에서도 사냥할 수 있었으며, 일부 종의 눈 지름은 25cm에 달했습니다.

특히 흥미로운 점은 익티오사우루스가 완전히 수중 생활에 적응해 육지로 올라올 필요가 없었다는 것입니다. 이들은 새끼를 낳았으며(난태생), 출산 중인 어미의 화석도 발견되었습니다.

반수생 공룡들

스피노사우루스 (Spinosaurus) 앞서 육식공룡 섹션에서 설명했듯이, 최근 연구에 따르면 스피노사우루스는 수생 생활에 적응한 최초의 수영하는 공룡이었을 가능성이 높습니다. 짧은 후지와 밀도 높은 뼈, 악어와 유사한 코와 이빨 구조, 그리고 패들 형태의 꼬리가 이를 뒷받침합니다.

바리오닉스 (Baryonyx) '무거운 발톱'이라는 뜻의 바리오닉스는 백악기 초기(약 1억 3,000만 년 전) 유럽에 살았습니다. 길이 약 9미터, 무게 1.5-2톤이었으며, 악어와 같은 길고 좁은 주둥이와 앞발에 30cm 길이의 큰 발톱이 특징이었습니다.

바리오닉스의 화석은 영국에서 발견되었는데, 위 내용물에서 물고기 비늘과 이빨이 발견되어 주로 물고기를 사냥했음이 확인되었습니다. 악어와 유사한 주둥이는 물고기를 잡는 데 특화되어 있었으며, 물가에서 대부분의 시간을 보냈을 것으로 추정됩니다.

수코미무스 (Suchomimus) '악어 모방자'라는 뜻의 수코미무스는 백악기 중기(약 1억 1,200만 년 전) 아프리카에 살았습니다. 길이 약 11미터, 무게 3-5톤이었으며, 바리오닉스와 마찬가지로 악어 같은 긴 주둥이가 특징이었습니다.

수코미무스는 물가에서 물고기와 작은 동물을 사냥했을 것으로 추정됩니다. 주둥이 끝에는 많은 날카로운 이빨이 있어 미끄러운 물고기를 효과적으로 잡을 수 있었습니다. 등에 작은 돛이 있었는데, 이는 체온 조절이나 시각적 디스플레이에 사용되었을 것입니다.

공룡 시대 여행
트라이아스기 (2억 5100만 년 전 - 2억 100만 년 전)
세계와 환경 트라이아스기는 '판게아'라는 하나의 거대한 초대륙이 존재하던 시기입니다. 지구 역사상 최대 규모의 대멸종(페름기-트라이아스기 대멸종)이 끝난 직후로, 생물 다양성이 회복되는 과정에 있었습니다. 기후는 대체로 덥고 건조했으며, 계절성 강수가 있었습니다. 대부분의 지역이 사막과 같은 환경이었으나, 열대와 아열대 지역에는 울창한 숲이 있었습니다.

식물상 트라이아스기의 주요 식물은 다음과 같습니다:

소철류(사이캐드): 야자나무와 비슷하게 생긴 나무
은행나무 조상들
고사리류
솔송나무
초기 침엽수 꽃이 피는 식물(현화식물)은 아직 등장하지 않았습니다.
공룡의 등장 트라이아스기 중기에 최초의 공룡들이 등장했습니다. 이 시기의 공룡들은 비교적 작고 빠른 육식 및 잡식성 동물들이었습니다. 대형 초식공룡인 프라테오사우루스와 같은 초기 사우로포도모프도 등장했습니다. 그러나 이 시기에는 공룡이 아직 지배적인 육상 동물은 아니었으며, 다양한 파충류와 공룡형 파충류들이 생태계의 중요한 부분을 차지했습니다.

대표 공룡들

코엘로피시스 (Coelophysis): 작고 빠른 초기 육식 공룡으로, 긴 목과 꼬리를 가졌습니다.
프라테오사우루스 (Plateosaurus): 초기 대형 초식 공룡으로, 사우로포드의 조상입니다.
에오랍토르 (Eoraptor): 가장 초기 공룡 중 하나로, 작고 이족보행하는 잡식성 공룡이었습니다.
헤레라사우루스 (Herrerasaurus): 초기 육식 공룡으로, 완전한 공룡의 특징을 아직 갖추지 않은 과도기적 형태를 보입니다.
트라이아스기의 끝 약 2억 100만 년 전, 대규모 화산 활동으로 인한 기후 변화와 환경 변화로 트라이아스기-쥐라기 경계 대멸종이 발생했습니다. 이때 많은 파충류 그룹이 멸종했지만, 공룡들은 살아남아 쥐라기에 번성할 수 있었습니다.

쥐라기 (2억 100만 년 전 - 1억 4500만 년 전)
세계와 환경 쥐라기에 들어서면서 판게아 대륙은 분리되기 시작했습니다. 로라시아(북반구)와 곤드와나(남반구)로 나뉘기 시작했고, 테티스해가 이들 사이로 밀고 들어왔습니다. 해수면이 상승하여 넓은 지역이 얕은 바다로 덮였습니다. 기후는 트라이아스기보다 따뜻하고 습했으며, 계절성이 감소했습니다. 극지방에도 빙하가 없었고, 전 세계가 온난했습니다.

식물상 쥐라기의 식물상은 다음과 같습니다:

소철류(사이캐드)의 번성
다양한 고사리류
침엽수림의 확장
초기 구과식물(침엽수)의 다양화
은행나무류의 번성 여전히 꽃피는 식물은 없었습니다.
공룡의 황금기 시작 쥐라기는 공룡의 다양성이 폭발적으로 증가한 시기입니다. 대형 사우로포드(목 긴 공룡)가 번성하기 시작했고, 다양한 육식공룡들이 등장했습니다. 또한 초기 갑옷 공룡과 각질 공룡이 등장했습니다. 쥐라기 후기에는 가장 유명한 공룡 중 일부가 번성했으며, 최초의 새(아르케옵테릭스)도 이 시기에 나타났습니다.

대표 공룡들

디플로도쿠스 (Diplodocus): 매우 긴 목과 꼬리를 가진 거대 초식 공룡입니다.
브라키오사우루스 (Brachiosaurus): 앞다리가 뒷다리보다 긴 대형 사우로포드입니다.
스테고사우루스 (Stegosaurus): 등에 판이 있는 특징적인 갑옷 공룡입니다.
알로사우루스 (Allosaurus): 쥐라기 후기 최상위 포식자였습니다.
아르케옵테릭스 (Archaeopteryx): 공룡과 새의 특징을 모두 가진 초기 조류입니다.
해양 파충류와 비행 파충류 쥐라기 바다에서는 익티오사우루스와 플레시오사우루스가 번성했으며, 하늘에서는 프테로닥틸과 같은 익룡들이 날아다녔습니다. 이들은 공룡이 아니지만, 공룡과 같은 시대에 살았던 파충류 그룹입니다.

백악기 (1억 4500만 년 전 - 6600만 년 전)
세계와 환경 백악기에는 대륙들이 계속 분리되어 현재와 더 비슷한 위치로 이동했습니다. 대서양이 넓어지기 시작했고, 인도가 북쪽으로 이동하며 히말라야 산맥 형성이 시작되었습니다. 기후는 쥐라기처럼 온난했지만, 백악기 후기에는 점차 냉각되기 시작했습니다. 화산 활동이 매우 활발했으며, 해수면은 역사상 가장 높은 수준 중 하나였습니다.

식물상 백악기의 가장 중요한 사건은 꽃피는 식물(현화식물)의 등장입니다. 이는 육상 생태계를 완전히 변화시켰습니다. 백악기의 식물상:

최초의 꽃피는 식물(약 1억 2500만 년 전)
최초의 잔디(백악기 말기)
낙엽수의 등장
현대적 침엽수림
소철류와 고사리류는 여전히 존재했지만 덜 지배적이었습니다.
공룡의 절정기와 멸종 백악기는 공룡의 다양성이 최고조에 달했던 시기입니다. 티라노사우루스 렉스, 트리케라톱스와 같은 가장 유명한 공룡들이 이 시기 후반에 살았습니다. 또한 깃털 공룡의 증거가 풍부하게 발견되어, 공룡과 조류의 연결성이 더욱 명확해졌습니다.

그러나 약 6600만 년 전, 대규모 소행성(지름 10-15km)이 현재의 멕시코 유카탄 반도(치쿨루브 분화구)에 충돌했습니다. 이 충돌로 인한 전 지구적 재앙(단기적인 극한 열, 장기적인 먼지로 인한 '암흑', 산성비, 산불, 쓰나미 등)으로 조류 공룡을 제외한 모든 공룡이 멸종했습니다.

대표 공룡들

티라노사우루스 렉스 (Tyrannosaurus rex): 백악기 최후기의 대형 육식 공룡입니다.
트리케라톱스 (Triceratops): 세 개의 뿔과 목 덮개를 가진 각질 공룡입니다.
벨로시랍토르 (Velociraptor): 깃털이 있는 소형 육식 공룡입니다.
파라사우롤로푸스 (Parasaurolophus): 머리에 관이 있는 오리주둥이 공룡입니다.
안킬로사우루스 (Ankylosaurus): 갑옷과 꼬리 곤봉을 가진 방어적 공룡입니다.
스피노사우루스 (Spinosaurus): 등에 돛을 가진 반수생 육식 공룡입니다.
미크로랍토르 (Microraptor): 네 개의 날개를 가진 깃털 공룡입니다.
백악기-제3기 대멸종 6,600만 년 전 발생한 이 대규모 멸종 사건으로 공룡뿐만 아니라 암모나이트, 모사사우루스, 익룡 등 많은 생물 그룹이 멸종했습니다. 그러나 일부 포유류, 조류(공룡의 후손), 파충류, 양서류, 어류 등이 살아남아 새로운 세계를 형성했습니다. 이 멸종 사건이 없었다면, 인간을 포함한 현대 포유류의 진화는 불가능했을 것입니다.

실제 크기 공룡 만나기 AR 앱을 통해 티라노사우루스, 브라키오사우루스, 트리케라톱스 등 다양한 공룡을 실제 크기로 만나보세요. 여러분의 방이나 학교 운동장, 공원에 거대한 공룡이 나타납니다! 공룡 옆에 서서 사진을 찍으며 그들의 실제 크기를 실감해보세요.

생동하는 공룡 생태계 AR로 고대 공룡 세계를 재현해보세요. 트라이아스기, 쥐라기, 백악기의 환경과 식물, 그리고 그 시대에 살았던 공룡들이 여러분 앞에서 살아 움직입니다. 화면을 통해 공룡들의 일상 생활, 사냥, 먹이 활동을 관찰해보세요.

공룡 해부학 탐험 AR 기술로 공룡의 내부 구조를 확인해보세요. 골격, 근육, 내장 기관 등을 3D로 볼 수 있으며, 각 부분을 터치하면 자세한 설명이 나타납니다. 티라노사우루스의 강력한 턱 근육, 브라키오사우루스의 거대한 심장, 벨로시랍토르의 발톱 메커니즘 등을 자세히 살펴볼 수 있습니다.

공룡 퀴즈 스캔 주변 물체를 스캔하여 그것과 관련된 공룡 정보와 퀴즈를 풀어보세요. 새를 스캔하면 깃털 공룡에 대한 정보가, 물을 스캔하면 해양 파충류에 대한 정보가 나타납니다!

공룡 도감 (전체 공룡 목록)
공룡 도감에서는 모든 주요 공룡들의 상세 정보를 한눈에 볼 수 있습니다. 아래는 주요 공룡들의 기본 정보입니다.

트라이아스기 공룡
코엘로피시스 (Coelophysis)

시대: 트라이아스기 후기 (2억 1,500만 년 전)
서식지: 북아메리카
크기: 길이 3m, 높이 1m, 무게 15-20kg
식성: 육식
특징: 가벼운 골격, 긴 꼬리, 빠른 움직임
프라테오사우루스 (Plateosaurus)

시대: 트라이아스기 후기 (2억 1,400만 년 전)
서식지: 유럽
크기: 길이 6-9m, 무게 600-4,000kg
식성: 초식
특징: 초기 사우로포도모프(목 긴 공룡의 조상), 엄지발톱
에오랍토르 (Eoraptor)

시대: 트라이아스기 후기 (2억 3,100만 년 전)
서식지: 남아메리카
크기: 길이 1m, 무게 10kg
식성: 잡식
특징: 가장 초기 공룡 중 하나, 크기가 작음
쥐라기 공룡
알로사우루스 (Allosaurus)

시대: 쥐라기 후기 (1억 5,000만 년 전)
서식지: 북아메리카
크기: 길이 8-12m, 무게 1.5-2.5톤
식성: 육식
특징: 눈 위의 뿔 같은 돌기, 강력한 턱, 날카로운 이빨
스테고사우루스 (Stegosaurus)

시대: 쥐라기 후기 (1억 5,000만 년 전)
서식지: 북아메리카
크기: 길이 9m, 무게 5-7톤
식성: 초식
특징: 등의 2열 판, 꼬리의 4개 가시, 매우 작은 뇌
디플로도쿠스 (Diplodocus)

시대: 쥐라기 후기 (1억 5,000만 년 전)
서식지: 북아메리카
크기: 길이 24-27m, 무게 10-16톤
식성: 초식
특징: 매우 긴 목과 꼬리, 연필 같은 이빨
브라키오사우루스 (Brachiosaurus)

시대: 쥐라기 후기 (1억 5,400만 년 전)
서식지: 북아메리카, 아프리카
크기: 길이 20-25m, 높이 13m, 무게 35-58톤
식성: 초식
특징: 앞다리가 뒷다리보다 김, 기린과 유사한 자세
컴프소그나투스 (Compsognathus)

시대: 쥐라기 후기 (1억 5,000만 년 전)
서식지: 유럽
크기: 길이 1m, 무게 3kg
식성: 육식
특징: 닭 크기, 빠른 움직임, 작은 도마뱀 사냥
백악기 공룡
티라노사우루스 렉스 (Tyrannosaurus rex)

시대: 백악기 최후기 (6,800-6,600만 년 전)
서식지: 북아메리카
크기: 길이 12-14m, 높이 4-6m, 무게 8-14톤
식성: 육식
특징: 강력한 턱, 작은 앞다리, 가능성 있는 깃털 덮개
트리케라톱스 (Triceratops)

시대: 백악기 최후기 (6,800-6,600만 년 전)
서식지: 북아메리카
크기: 길이 8-9m, 무게 6-12톤
식성: 초식
특징: 세 개의 뿔, 큰 목 덮개(프릴), 앵무새 같은 부리
벨로시랍토르 (Velociraptor)

시대: 백악기 후기 (7,500만 년 전)
서식지: 몽골, 중국
크기: 길이 2m, 무게 15kg
식성: 육식
특징: 깃털 덮개, 발에 큰 발톱, 지능이 높음
파라사우롤로푸스 (Parasaurolophus)

시대: 백악기 후기 (7,600만 년 전)
서식지: 북아메리카
크기: 길이 10m, 무게 2.5톤
식성: 초식
특징: 머리 뒤로 1.8m 길이의 중공 관, 소리 내는 데 사용
안킬로사우루스 (Ankylosaurus)

시대: 백악기 최후기 (6,800-6,600만 년 전)
서식지: 북아메리카
크기: 길이 8-9m, 무게 6톤
식성: 초식
특징: 갑옷 같은 등, 꼬리 끝의 골질 곤봉
스피노사우루스 (Spinosaurus)

시대: 백악기 중기 (1억 1,200-9,400만 년 전)
서식지: 북아프리카
크기: 길이 15-18m, 무게 7-20톤
식성: 주로 물고기, 때로는 육식
특징: 등의 1.5-2m 돛, 악어 같은 주둥이, 수생 적응
마이아사우라 (Maiasaura)

시대: 백악기 후기 (7,600만 년 전)
서식지: 북아메리카
크기: 길이 9m, 무게 3-4톤
식성: 초식
특징: '좋은 어미 도마뱀'이라는 뜻, 새끼 돌봄 행동 증거
학부모/교사 자료실
초등학생들이 공룡에 대해 배우면서 다양한 과학 개념과 역사적 사고를 발전시킬 수 있도록 도와주는 자료들을 제공합니다.

연령별 학습 가이드
저학년 (1-2학년) 가이드

공룡의 기본 개념: 육식 vs 초식, 크기 비교, 간단한 분류
활동 중심: 색칠하기, 간단한 공룡 만들기, 공룡 소리 흉내내기
추천 주제: "가장 큰 공룡", "가장 작은 공룡", "공룡은 무엇을 먹었나요?"
중학년 (3-4학년) 가이드

공룡의 시대 이해: 트라이아스기, 쥐라기, 백악기의 차이
공룡의 몸 구조와 적응: 다양한 특징과 생존 전략
추천 주제: "공룡은 어떻게 움직였나요?", "공룡의 방어 전략", "공룡의 사냥 방법"
고학년 (5-6학년) 가이드

진화와 적응: 공룡이 다양한 환경에 어떻게 적응했는지
과학적 방법: 화석 증거를 통한 추론 방법, 가설 설정
추천 주제: "공룡과 조류의 관계", "공룡의 멸종", "공룡 연구의 최신 발견"
수업 계획 및 활동지
수업 계획 예시: "공룡 탐험가가 되어보자" (3-4학년, 5차시)

1차시: 공룡의 세계 소개 (시대, 주요 종류)
2차시: 공룡 화석 탐구 (화석은 어떻게 형성되는가?)
3차시: 나만의 공룡 설계하기 (적응과 진화 이해)
4차시: 공룡 서식지 만들기 (생태계와 환경 이해)
5차시: 공룡 전시회 (학습 내용 공유 및 발표)
수업 활동지 예시:

공룡 분류 활동지: 다양한 공룡 그림을 육식/초식, 시대별, 서식지별로 분류하기
공룡 크기 비교 활동지: 실제 크기로 그려진 공룡 발자국 측정하기
공룡 먹이사슬 활동지: 백악기 생태계의 먹이사슬 완성하기
공룡 적응 활동지: 특정 환경에 맞는 공룡 특징 설계하기
과학 표준에 맞춘 교육 자료
과학적 탐구 기술:

관찰과 추론: 공룡 화석을 통해 생김새와 행동 추론하기
데이터 수집과 분석: 다양한 공룡의 크기, 속도, 식성 데이터 비교하기
모델 만들기: 공룡의 움직임, 생태계, 멸종 과정 모델링하기
지구과학 연계:

지질 시대와 층서학: 공룡 시대의 지층 이해하기
기후 변화: 중생대의 기후와 현재 기후 비교하기
대륙 이동: 판게아에서 현대 대륙으로의 변화 이해하기
생물학 연계:

진화와 적응: 공룡의 다양한 특징이 환경 적응에 어떻게 도움이 되었는지
분류학: 공룡의 계통학적 분류와 현대 동물과의 관계
생태계와 상호작용: 중생대 생태계에서 공룡의 역할 이해하기
공룡 관련 책과 미디어 추천

"화석 탐험가의 모험" - 화석 발굴의 과정을 소개하는 이야기책

"공룡의 행성" - 최신 과학 연구를 바탕으로 한 공룡 생태 다큐멘터리
"타임 트래블: 공룡 시대" - 각 시대별 공룡 세계를 탐험하는 시리즈
"화석 헌터스" - 실제 고생물학자들의 발굴 과정을 따라가는 다큐멘터리
교육용 앱 및 웹사이트:

"디노월드 AR" - 증강현실로 공룡을 만나는 교육용 앱
"화석 퍼즐" - 공룡 골격을 맞추며 해부학을 배우는 게임
"타임라인 익스플로러" - 공룡 시대를 인터랙티브하게 탐험하는 웹사이트
이 자료들은 교실과 가정에서 공룡에 대한 학습을 더욱 풍부하고 의미 있게 만들어 줄 것입니다. 아이들의 호기심을 자극하고 과학적 사고력을 발전시키는 데 도움이 될 것입니다.

복사
공룡의 크기를 비교하는 인포그래프를 만들고 싶어. 시대 구분 말고 우리가 작업 중인 공룡 월드에 나오는 공룡들로만 만들고 싶으니 방법을 알려줘.

실루엣: 공룡들의 정확한 비율의 측면 실루엣 사용
상세도: 주요 공룡은 실루엣과 함께 더 상세한 그림 추가
팝업 정보: 각 공룡에 대한 간략한 정보 박스 추가
눈금: 배경에 1m 또는 5m 간격의 눈금선 배치
비교 요소
현대적 비교물: 인간, 버스, 기린, 코끼리, 건물 등 친숙한 물체 실루엣 포함
집중 비교: 특정 신체 부위(두개골, 발톱 등)만 별도로 비교하는 작은 차트 추가
4. 인포그래픽 제작 도구
디자인 소프트웨어 옵션
어도비 일러스트레이터/포토샵: 전문가급 디자인
캔바(Canva): 사용하기 쉬운 온라인 도구로 템플릿 활용 가능
파워포인트/구글 슬라이드: 접근성 높은 기본 도구
Infogram/Piktochart: 인포그래픽 특화 온라인 도구
필요 자료
정확한 공룡 실루엣 이미지(과학적으로 검증된)
스케일 측정을 위한 그리드/눈금
일관된 폰트와 색상 팔레트
공룡월드 로고 및 브랜딩 요소
5. 인포그래픽 제작 단계
자료 수집: 모든 공룡의 크기 데이터 수집 및 정리
스케일 결정: 가장 큰 공룡(아르겐티노사우루스)과 가장 작은 공룡(컴프소그나투스)을 포함할 수 있는 적절한 스케일 설정
기본 레이아웃 제작: 눈금과 기준선 설정
공룡 실루엣 배치: 스케일에 맞게 모든 공룡 실루엣 배치
색상 및 그룹화: 카테고리별 색상 적용 및 논리적 그룹화
정보 추가: 이름, 크기 데이터, 간략한 특징 추가
디자인 개선: 시각적 계층구조 개선, 가독성 확인
검토: 과학적 정확성 및 디자인 일관성 검토
6. 특별 아이디어
인터랙티브 버전
웹사이트에 줌인/줌아웃 가능한 인터랙티브 인포그래픽 구현
공룡을 클릭하면 상세 정보와 3D 모델이 나타나는 기능
사용자가 자신의 키를 입력하여 공룡과 비교할 수 있는 기능
테마별 비교
"육식공룡의 진화" - 시간에 따른 육식공룡의 크기 변화
"머리에서 꼬리까지" - 각 공룡의 두개골, 목, 몸통, 꼬리 비율 비교
"무게 대 크기" - 크기와 체중의 관계를 보여주는 별도 차트
물리적 전시용 버전
학교 복도나 과학관에 설치할 수 있는 대형 출력물 디자인
바닥에 공룡 발자국을 실제 크기로 표시한 보조 전시물

        function createMeasurementGrid() {
            const gridContainer = document.getElementById('measurement-grid');
            const maxHeight = 20; // 최대 높이(m)
            
            // 수평선
            for (let i = 0; i <= maxHeight; i += 5) {
                const gridLine = document.createElement('div');
                gridLine.className = 'grid-line';
                gridLine.style.bottom = `${(i / maxHeight) * 100}%`;
                
                const gridLabel = document.createElement('div');
                gridLabel.className = 'grid-label';
                gridLabel.style.bottom = `${(i / maxHeight) * 100}%`;
                gridLabel.textContent = `${i}m`;
                
                gridContainer.appendChild(gridLine);
                gridContainer.appendChild(gridLabel);
            }
            
            // 수직선
            for (let i = 0; i <= 4000; i += 200) {
                const gridLine = document.createElement('div');
                gridLine.className = 'grid-line-vertical';
                gridLine.style.left = `${i}px`;
                gridContainer.appendChild(gridLine);
            }
        }
        
        // 공룡 추가
        function addDinosaurs() {
            const container = document.getElementById('scale-container');
            
            dinosaurData.forEach(dino => {
                const dinosaurElement = document.createElement('div');
                dinosaurElement.className = `dinosaur ${dino.type}`;
                dinosaurElement.style.left = `${dino.position}px`;
                dinosaurElement.style.height = `${dino.height * 20}px`; // 20px = 1m
                
                // 실루엣 추가
                dinosaurElement.innerHTML = dino.silhouette;
                
                // 라벨 추가
                const labelElement = document.createElement('div');
                labelElement.className = 'dino-label';
                labelElement.innerHTML = `
                    <span class="dino-name">${dino.name}</span>
                    <span class="dino-info">길이: ${dino.length}m, 무게: ${dino.weight}톤</span>
                `;
                
                dinosaurElement.appendChild(labelElement);
                container.appendChild(dinosaurElement);
            });
        }
        
        // 페이지 로드 시 실행
        window.addEventListener('DOMContentLoaded', () => {
            createMeasurementGrid();
            addDinosaurs();
        });

코드 사용 설명
파일 저장: 이 코드를 dinosaur-comparison.html와 같은 이름으로 저장합니다.

브라우저에서 열기: 저장한 HTML 파일을 웹 브라우저에서 직접 열면 인포그래픽을 볼 수 있습니다.

특징:

SVG 실루엣을 사용하여 공룡 형태를 표현
색상으로 구분된 공룡 분류(초식/육식/비행/해양)
5m 간격의 측정 그리드
각 공룡의 이름, 길이, 무게 정보 표시
가로 스크롤로 모든 공룡 탐색 가능
반응형 디자인으로 다양한 화면 크기 지원
사용자 정의:

dinosaurData 배열에 공룡을 추가하거나 수정할 수 있습니다
SVG 실루엣을 더 정확한 이미지로 대체할 수 있습니다
색상, 크기, 위치 등을 CSS에서 조정할 수 있습니다
주의 사항:

SVG 실루엣은 단순화되어 있으므로 필요에 따라 더 정교한 SVG로 대체하는 것이 좋습니다
많은 수의 공룡을 추가할 경우 성능에 영향을 줄 수 있습니다
이 코드는 기본적인 HTML, CSS, JavaScript만을 사용하여 브라우저에서 바로 작동하는 인포그래픽을 제공합니다. 웹사이트에 통합하거나 더 많은 기능을 추가하여 확장할 수 있습니다.
